# Internetradio (Material 3 PWA)

Moderns **Google Material Design 3 (Material You)** internetradio atskaņotājs, ko var instalēt kā pilnvērtīgu aplikāciju (PWA) Android, iOS, Windows un macOS ierīcēs tieši no pārlūkprogrammas.

## Kā publicēt uz GitHub (visi faili vienā mapē)

1. Izveidojiet jaunu repozitoriju vietnē [GitHub](https://github.com/new) (piemēram, `internetradio`).
2. Atarhivējiet šo ZIP failu un augšupielādējiet visus 8 failus (`index.html`, `manifest.json`, `sw.js`, `.nojekyll`, `README.md`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`) tieši repozitorija galvenajā mapē (**Add file → Upload files**).
3. Repozitorijā atveriet **Settings → Pages**.
4. Sadaļā **Build and deployment → Source** izvēlieties **Deploy from a branch**, norādiet zaru `main` un mapi `/ (root)`, un nospiediet **Save**.
5. Atveriet ģenerēto `https://<jusu-lietotajvards>.github.io/internetradio/` saiti tālruņa **Chrome** vai **Safari** pārlūkprogrammā un izvēlieties **"Instalēt lietotni"** (*Install app* / *Add to Home Screen*).
